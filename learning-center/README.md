# 교육 포털 · SOLAPI 문자 발송 실행 안내

## 실행 준비

1. Node.js 22 이상이 설치된 PC에서 압축을 풉니다.
2. `.env.example` 파일을 복사해 `.env`로 저장합니다. Windows 탐색기에서 파일 확장명 표시를 켜 `.env.txt`가 되지 않도록 합니다.
3. `.env`에 아래 값을 입력합니다. 키와 비밀키는 HTML 또는 채팅에 입력하지 않습니다.
   - SOLAPI_API_KEY: SOLAPI 콘솔에서 발급한 API Key
   - SOLAPI_API_SECRET: 해당 API Secret
   - SOLAPI_FROM: SOLAPI에 사전 등록한 발신번호, 하이픈 제외
   - SMS_ADMIN_TOKEN: 직접 정한 관리자 발송 암호, 8자 이상
   - PORT: 기본 8787
4. Windows에서는 `start.cmd`를 실행하거나 터미널에서 `node --env-file=.env server.mjs`를 실행합니다.
5. 브라우저에서 http://127.0.0.1:8787 에 접속합니다. 서버를 실행한 PC에서만 접속합니다.

별도 npm 설치는 필요하지 않습니다. PDF 처리 및 Office 이미지 추출 기능은 기존처럼 외부 도구를 불러오기 위해 인터넷 연결이 필요합니다.

## 사용법

- 교육신청: 휴대폰 연락처를 입력하고 제출합니다. 현재 010으로 시작하는 국내 11자리 번호를 지원합니다.
- 기존 신청자: 신청현황에서 연락처 수정을 눌러 번호를 추가·수정합니다.
- 신청현황: 교육과정 콤보박스에서 모든 교육과정(신청 0건 포함)을 선택할 수 있고, 전체 교육과정으로 돌아갈 수 있습니다.
- 전체 발송: 현재 교육과정·검색·상태 필터에 표시되는 전체 신청 내역을 기준으로 합니다.
- 선택 발송: 현재 목록에서 체크한 신청 내역을 기준으로 합니다.
- 취소·반려, 누락·형식 오류 연락처, 삭제된 과정은 제외합니다.
- 한 번에 최대 1,000건입니다. 동일 번호·동일 본문은 하나만 전송합니다. 같은 번호로 서로 다른 교육 안내가 있으면 각 안내가 전송됩니다.
- 교육신청 확인 또는 수강 전 안내 양식을 고르고 문의처·준비사항·본문을 수정합니다.
- 미리보기에서 수신번호와 개인별 내용을 확인하고 관리자 발송 암호를 입력해 전송합니다.
- 자동 발송이나 예약 발송은 포함하지 않습니다. 신청 확인도 담당자가 목록에서 직접 발송합니다.
- SMS/LMS는 SOLAPI의 autoTypeDetect로 구분합니다. 본문은 1,800자 이하로 제한합니다. 사용량과 문자 유형에 따른 비용은 SOLAPI 계정에서 확인합니다.
- 접수 성공은 최종 수신 완료가 아닙니다. 최종 결과는 SOLAPI 콘솔 발송 내역에서 확인합니다.
- 접수 실패 항목은 화면에 표시합니다. 접수 여부 확인 필요가 나오면 SOLAPI 발송 내역을 먼저 확인하고 임의로 반복 발송하지 않습니다.

## 연결 구조와 검증 범위

- 브라우저 → 로컬 서버 `/api/sms/send` → SOLAPI `POST https://api.solapi.com/messages/v4/send-many/detail`
- 서버는 API Secret을 키로, ISO 시각 + 요청마다 다른 랜덤 salt를 데이터로 HMAC-SHA256 서명을 생성합니다.
- 발송 요청 ID 및 결과는 서버 폴더 `sms-ledger.json`에 저장합니다. 같은 요청 ID 재시도 시 기존 결과를 반환하고 재발송하지 않습니다. 통신 결과 불명확 시도 자동 재발송하지 않습니다.
- 프로그램은 로컬 단일 서버 실행을 전제로 합니다. 여러 서버 인스턴스가 같은 ledger를 공유해 실행하는 구성은 지원하지 않습니다.
- API 비밀키는 서버 환경변수에만 둡니다. 관리자 발송 암호는 브라우저 저장소에 저장하지 않습니다.
- 기존 신청 내역·강사 정보는 브라우저 localStorage 기반입니다. 이 서버 접속 주소에서 기존 HTML 파일과 저장소가 달라 기존 내역이 자동 이전되지 않습니다. 현재 구성은 여러 PC가 공유하는 운영용 LMS가 아닙니다.
- HTML 파일만 직접 열어도 휴대폰 입력·문자 미리보기는 가능하지만 실제 문자는 서버 실행 화면에서만 발송할 수 있습니다.
- 실제 SOLAPI 계정과 수신번호를 이용한 실발송은 수행하지 않았습니다. 서버 인증·서명, 중복 요청·결과 불명확 처리, 응답 집계는 모의 시험으로 확인했습니다. 브라우저 화면 조작 검증은 수행하지 못했습니다.
- 운영 적용 전 개인정보 처리 및 관리자 접근 권한은 회사 기준에 맞춰 검토해야 합니다.

공식 문서 확인 기준: 2026-10-29
- https://solapi.com/developers/api/authentication-api-key
- https://solapi.com/developers/api/messages

## 교육과정 상세 및 과정개요서 출력

- 관리자 관리 → 교육과정 등록/수정에서 교육대상·학습목표·커리큘럼·준비물·주요 안내사항을 입력합니다.
- 교육과정 목록 → 상세내용에서 교육 정보를 확인합니다. 강사가 지정되어 있으면 강사 프로필 버튼으로 학력·경력·주요강의·저서 등을 확인하고 과정 상세로 돌아갈 수 있습니다.
- 상세내용 → 과정개요서 출력을 누르면 A4 세로 1페이지 인쇄 양식이 열립니다. 프린터 또는 PDF로 저장을 선택할 수 있습니다.
- 출력 하단에는 흥국금융그룹 HRD 문의처와 주소를 고정 표기합니다. 긴 내용은 자동 축소되므로 미리보기에서 글씨 크기를 확인하세요. 브라우저 인쇄 설정은 A4, 배율 100%, 머리글/바닥글 해제를 권장합니다.
- 기존 과정의 추가 항목은 자동 생성하지 않습니다. 관리자 화면에서 내용을 보완하세요.

## 관리자 로그인 및 비밀번호 변경

- 좌측 일반 메뉴에는 교육과정 목록·교육신청·관리자 관리만 표시합니다. 신청현황과 강사이력 관리는 관리자 관리의 내부 탭에서 사용합니다.
- 관리자 관리 최초 접속 시 8~128자의 새 비밀번호와 확인값을 입력해 설정합니다. 초기 공통 비밀번호는 없습니다.
- 이후에는 설정한 비밀번호로 입장합니다. 관리자 화면 상단의 비밀번호 변경에서 현재 비밀번호와 새 비밀번호를 입력해 언제든 변경할 수 있습니다. 로그아웃 버튼으로 관리자 화면을 종료합니다.
- 서버 실행 시 비밀번호는 scrypt 해시로 admin-password.json에 저장하며, 로그인은 30분 유효한 HttpOnly·SameSite 세션 쿠키로 관리합니다. 비밀번호 변경 시 기존 세션은 모두 종료하고 현재 사용자에게 새 세션을 발급합니다. 로그인 시도는 1분에 10회로 제한합니다.
- 첫 설정은 서버 실행 PC의 로컬 화면에서 진행하세요. admin-password.json과 sms-ledger.json, .env는 실행 데이터이므로 공유하거나 배포 패키지에 포함하지 않습니다.
- HTML 단독 실행 시에는 PBKDF2 해시를 해당 브라우저 localStorage에 저장하는 화면 잠금입니다. 개발자 도구나 브라우저 저장소 접근 자체를 차단하는 운영용 인증은 아닙니다. 비밀번호 변경은 해당 브라우저에만 반영되며 서버 설정과 별개입니다.
- 기존처럼 신청 내역과 강사 데이터는 브라우저 저장소에 있습니다. 서버 로그인 추가만으로 여러 PC가 공유하는 데이터베이스나 신청자별 접근권한이 구성되는 것은 아닙니다.
- 문자 발송에는 관리자 로그인과 별도로 기존 SMS_ADMIN_TOKEN 발송 암호가 필요합니다. API Secret과 관리자 로그인 비밀번호는 서로 별개입니다.

## Render 배포 준비

- Node 웹 서비스 시작 명령: `npm start`, 상태 점검 경로: `/health`.
- Render에서는 PORT와 0.0.0.0 바인딩, RENDER_EXTERNAL_URL의 호스트·HTTPS Origin, Secure 세션 쿠키를 사용합니다.
- 공개 배포 전 Render 비밀 환경변수 ADMIN_INITIAL_PASSWORD에 8자 이상 초기 관리자 비밀번호를 설정해야 합니다. 미설정 시 관리자 초기 설정을 차단합니다.
- DATA_DIR는 영구 저장소 경로로 지정해야 관리자 비밀번호 변경과 문자 중복 방지 기록이 재배포 후에도 유지됩니다. 브라우저 저장소에 있는 교육·신청 데이터의 공유는 별도 서버 데이터 저장 구현이 필요합니다.
- GitHub에는 .env와 실행 중 생성된 관리자 비밀번호·문자 기록 파일을 올리지 않습니다.
