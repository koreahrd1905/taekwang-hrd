# Google 스프레드시트 공용 저장소 연결

이 기능은 준비 브랜치에 구현되어 있습니다. 실제 Google 계정 연결·시트 생성·Apps Script 웹 앱 배포·Render 환경변수 설정이 모두 끝나기 전에는 공용 저장 완료로 볼 수 없습니다.

## 저장 구조

- 교육과정: 일정·시간·장소·정원·강사 연결·교육내용
- 교육신청: 신청자 정보·휴대폰·과정·신청상태
- 강사정보: 학력·경력·강의이력·저서·연락처
- _저장소: 비공개 기준 데이터·강사 사진과 저장 버전. 숨김 탭이며 삭제하거나 직접 수정하지 않습니다.

보기용 탭은 웹에서 저장한 내용을 표로 보여 줍니다. 보기용 셀을 직접 수정해도 웹에 반영되지 않습니다. 수정은 웹 관리자 화면에서 진행합니다. 사진은 셀 길이를 고려해 여러 셀에 나눠 기준 데이터에 보관합니다.

## 최초 연결

1. Google Drive를 설치·연결한 후, 전용 스프레드시트를 생성합니다. 파일 공유는 관리자만 접근하도록 비공개로 유지합니다. 직원에게 시트를 공유할 필요는 없습니다.
2. 스프레드시트 → 확장 프로그램 → Apps Script를 열고 `Code.gs`의 내용을 넣습니다.
3. Apps Script의 프로젝트 설정 → 스크립트 속성에 `SPREADSHEET_ID`(시트 주소 /d/ 다음 ID)와 `SHARED_SECRET`(무작위 32자 이상)을 설정합니다. 비밀값은 코드나 GitHub에 입력하지 않습니다.
4. `setupSheets` 함수를 한 번 실행하고 Google의 권한 승인을 완료합니다.
5. 배포 → 새 배포 → 웹 앱. 실행 사용자: 나 / 액세스 권한: 모든 사용자. 배포 후 `/exec`로 끝나는 웹 앱 URL을 복사합니다. 공개 웹 앱이어도 서버의 HMAC 인증을 통과한 요청만 데이터를 읽고 쓸 수 있습니다. 회사 Google Workspace 정책상 외부 웹 앱이 금지된 경우 관리자 확인이 필요합니다.
6. Render Environment에 `GOOGLE_SHEETS_WEB_APP_URL`(웹 앱 URL)과 `GOOGLE_SHEETS_SHARED_SECRET`(앞서 설정한 비밀값)을 입력합니다. 기존 관리자 비밀번호·SOLAPI 설정은 유지합니다.
7. 저장소 준비 브랜치의 코드를 운영 배포 브랜치에 반영한 후 재배포합니다. 저장소 연결 시험이 통과하기 전까지 기존 운영 브랜치를 그대로 둡니다.
8. 관리자 화면에서 최신 내역 불러오기를 누릅니다. 기존 PC에 자료가 있으면 기존 브라우저 자료 가져오기로 공용 시트에 이전합니다. 자동으로 기존 자료를 지우거나 합치지 않습니다.

## 동작과 검증

- 일반 직원은 공개 과정과 공개 강사 소개만 받습니다. 신청내역·연락처는 공개 API에 포함하지 않습니다.
- 관리자 전체 조회·과정/강사 변경·신청 승인/연락처 수정·리셋은 Render 서버의 관리자 세션을 확인합니다.
- 신규 신청은 스크립트 잠금 안에서 중복 사번과 정원 초과를 검사합니다. 같은 신청 요청을 재시도해도 중복 저장하지 않습니다.
- 관리자가 오래된 화면으로 저장하면 버전 충돌로 거절합니다. 새 신청을 덮어쓰지 않습니다.
- 기준 데이터는 이중 저장 슬롯에 쓴 뒤 활성 포인터를 바꿉니다. 보기용 탭 갱신 실패가 기준 데이터를 되돌리지 않습니다.
- 자료업로드의 PDF/PPTX/Word 원본은 브라우저에서 분석하며 시트에 원본 파일을 보관하지 않습니다.
- 리셋 시 모든 사용자의 과정·신청·강사 정보가 삭제되므로 확인창에서 범위를 확인합니다.
- 데이터는 Google 계정의 시트에 보존되므로 Render 재시작 때 지워지지 않습니다. 관리자 비밀번호와 문자 중복방지 기록의 기존 서버 파일 구조는 이번 과정·신청·강사 저장소와 별개입니다.
- Apps Script와 Google Sheets에는 계정별 실행·용량 한도가 있습니다. 추가 유료 서비스는 자동으로 만들지 않으며, 소규모 사내 교육 운영을 전제로 합니다.

## 연결 완료 판정

서로 다른 브라우저 2개에서 과정 공유 및 교육신청 저장을 확인하고, 비로그인 상태에서 관리자 조회가 401로 거절되는지 확인해야 합니다. 현재 자동 시험은 모의 저장소 기준이며 실제 Google 시트 연동 시험은 계정 연결 후 수행합니다.
